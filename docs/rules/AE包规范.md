# AE 重建包规范（做分镜 / 交付 AE 包时读）

沿用自「艾唯说挖洞」的规范（用户 2026-11-12 提出的分层要求在白帽志同样适用）。AE 生成器和检查工具在 P6 改造完成前，先看提交 `adbbc35` 里 `ae/_from_aiwei-vs2/` 的参考实现理解做法（取回：`git checkout adbbc35 -- ae/_from_aiwei-vs2`），不要直接运行它（里面还是挖洞号的颜色、字体和 HUD）。

- 分镜那一步同时交付 AE 重建包（.jsx 脚本 + 素材，打成 zip），和分镜图一起发给用户。之后画面有改动，MP4 和 AE 脚本同步更新。
- AE 脚本只能用 ES3 写法；形状和效果属性要用「每次重新获取」的写法（添加新属性后，AE 会让之前拿到的引用失效）。
- 交付前用模拟 AE 对象模型的测试跑通全部关键帧和表达式；真 AE 跑不了，要如实告诉用户没在真 AE 里测过。

## 顶部章节进度条区
画面顶部 76px（7%）留给章节进度条，由用户剪辑时放置：AE 包里这一条只有背景板 / 背景动态层，不放任何内容图层（检查工具 P6 会拦）。

## 必须分层，不许整帧烘焙
1. **背景板**：单独的图片文件，最底层，图层名 `背景板_BG3` / `背景板_BG2`（或备用的 `背景板_BG1`），直接用 `libs/backgrounds/plates/` 的 PNG。
2. **动态背景**：点阵、十字标、焦点组件（光晕 / 刻度环 / 刻度）、雷达线、扫描扇区等，单独做成 SVG 或 MP4 图层（图层名以 `背景动态_` 开头），能隐藏、能替换。BG3 焦点组件三层的锚点放在 SVG 中心 (500,500)，位置 = 本镜头主体中心，缩放 = scale × 100%，刻度层每秒转 4°（`BMAE.sweepSpin(layer, at, tEnd, {deg_per_s: 4})`）；BG1 扫描扇区绕雷达中心 (1440,540) 旋转。
3. **录屏**：「窗口边框」图片层 + 「录屏窗口」预合成（录屏原片素材层 + 时间重映射 + 缩放 / 位置关键帧做推镜 + 标注形状层）。用户在项目面板对录屏原片「替换素材」即可换录屏。
4. **信息卡、标签、文字、贴纸**：各自单独成层（文字转 AE 文字层）+ 入场关键帧；会变化的元素用多个状态图层。
- 只有 AE 里确实做不出来的局部效果才允许烘焙成局部小视频（不含背景、不含窗口），并在本期说明里写明。
- 检查工具（P6）硬检查：出现整帧视频层（从 0,0 起、宽 1920，且图层名不以 `背景动态_` 开头）或某个镜头没有背景层，就拒绝打包。

## 白帽志特有
- 没有 HUD、时间码、角标层；不做左上角 IP 区检查。
- 颜色、字体从 `tokens/brand.json` 读，不在 AE 脚本里手写色值。
- 字体全部随包附带：得意黑 `SmileySans-Oblique`、Archivo `Archivo-Black`、IBM Plex Mono `IBMPlexMono-Medium / SemiBold`（OFL），MiSans `MiSans-Medium / Bold / Heavy`（小米许可，用户已确认商用）。
- 人物 A-roll 素材层图层名以「人物占位_请替换」开头。

## 动效
- AE 端动效一律用 `ae/motion_ae.jsx`（`#include`），数值来自 `ae/motion_data.jsx`（由 `tokens/motion.json` 生成），和网页是同一条曲线；不要在 AE 脚本里手写缓动数值。
- 位置要先拆分维度（X / Y 单独加关键帧），时间缓动才和网页逐维一致。
- 线性擦除 / 径向擦除的参数按序号访问，擦除方向还没在真 AE 里核对过，第一次用时要检查。

## AE 相关踩坑（沿用）
- AE 接口名、属性 matchName 不能凭记忆写：先查官方文档副本（`git clone https://github.com/docsforadobe/after-effects-scripting-guide.git ae/aedocs`），再以 `ae/probe/` 里用户真实 AE（24.6.2）的探测报告为准；用户换 AE 版本或电脑后，让用户重跑探测脚本并更新报告。
- AE 文字换行必须是真正的换行符（Python 里写 `'\r'`，不是 `'\\r'`）；中英混排要逐字设字体，生成时有缺字形要直接报错。
