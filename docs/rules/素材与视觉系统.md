# 视觉系统与素材规则（动手做画面、选排版、生图时读）

## 视觉系统 1.0
- 开工前按顺序读：`STYLE.md` → `docs/rules/用户要求汇总.md` → `EPISODES.md` → `SETUP.md`。
- 只用 1.0 已有的色板、字体、组件、动效。不要临时改色值、字体或发明新风格；确实要改，先问用户，确认后改 `tokens/brand.json`，跑 `tools/gen_tokens.py` + `tools/contrast_check.py`，再更新 `STYLE.md`、`CHANGELOG.md` 并升版本号。
- 画面里不写私有色值：网页一律用 `engine/tokens.css` 的变量和 `scene-A` / `scene-B` 场景类。

## 一个镜头怎么搭
1. 选场景：A 炭黑场（默认）或 B 奶油白场（信息多的图解、清单、对比）。
2. 选背景板：A 用 BG1（底板 + 雷达线 + 扫描扇区），B 用 BG2（底板 + 雷达线）；网页里用 `libs/backgrounds/backgrounds.js` 的 `BGLIB.mount` 挂，演示 / 预览也一样；转场用 FX 闪切。
3. 选排版（`cards/layouts/`，按 README 里「用来讲什么」一栏挑；P6 后查配方表 `cards/recipes/`）。改排版或新增排版后跑 `python3 tools/layout_lint.py` 和 `node tools/layout_preview.js`。
4. 往槽位里填信息卡（`cards/infocards/`）和素材（贴纸 / 截图 / 用户素材）。
5. 套动效（`engine/motion/`）。

## 画面
- 画面丰富度要高：知识卡片 + 透明底贴纸是丰富画面的主要手段，不能丢；但每屏仍只有一个主体。
- 动效要达到顶尖动态设计师、作品集级别的水准。
- 开场排版要美观，核心内容在第一帧就出现。
- 背景不用位图，用背景板库或其他矢量 / 程序化背景；位图只放在手机屏幕、窗口、卡片里，或作为贴纸。
- 用户提供的素材（截图、PDF、标志等）都要用进画面。
- 示意性的新闻、公告、通知必须标「示意 / 教学示例」，不能冒充真实机构或真实报道。

## 素材规则
- **与艾唯说挖洞隔离**：不得复制、引用 `aiwei-vs2` 的任何素材（`assets/`、`cards/examples_assets/`、往期 `episodes/*/assets/`、黏土角色、SC-01、黑白雕塑、人物静帧）。挖洞号 49 张卡只借构图，在排版库里重做。
- **不设品牌素材层**：图片素材（贴纸、角色、双色调照片）由用户提供，或按本期口播现生成，不跨期复用。`cards/images/samples/` 是风格样张，不进正片。
- 新一期的素材放进本期目录 `episodes/<本期>/assets/`。同一张生图不得出现在两期；交付前对照 `EPISODES.md` 的素材使用记录逐条核对，并登记本期新用的素材。
- 同一期的不同分段之间可以复用生图。

## 素材生成
- 图片风格从 `cards/images/styles.json` 选（含 `sticker` 陶瓷贴纸、`sc02-line` / `sc02-duo` SC02 蓝调漫画等）：生图清单里每张写明风格 id、镜头、口播、文件名和本期的画面描述；`tools/genimg.py` 的 preset 直接用风格 id。
- 生图、生视频的 API 由 `apihub.agnes-ai.com` 提供，云环境的网络代理注入密钥。
- 生图必须 `response_format=b64_json`（图片 URL 域名被网络策略拦截）；免费额度约连续 10 张后限流，用 `tools/genimg.py` 串行生成。
- 抠图：物件用 `tools/cutout.py object`，人像用 `person`（`u2net_human_seg`，对深色衣服更稳）。实心物件加 `--fill-holes`；锁、钥匙这类有镂空的不要加。
- HuggingFace 被网络策略拦截：模型一律从 GitHub releases 下载（见 `SETUP.md`）。
