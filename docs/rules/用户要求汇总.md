# 用户要求汇总（每次开工先读）

来源：2026-11-25 ~ 11-26 建号对话，以及「艾唯说挖洞」AW01 起用户提过、确认沿用到白帽志的要求。已写进 `CLAUDE.md` / `STYLE.md` 的硬规则这里不重复。

## 一、账号与视觉方向（2026-11-25 ~ 26）
1. 账号名「艾唯白帽志」（唯，不是维），讲 AI 挖洞、攻防技术、网安就业。
2. **视觉风格要和「艾唯说挖洞」有明显差异**。差异要从配色、字体、版式、贴纸质感、动效一起拉开，不能只换颜色。
3. **配色偏好（几轮试下来的结论）**：
   - 炭黑 + 朱橙为核心，克莱因蓝为辅；选朱橙 `#FF5A1F`（用户在 4 档橙色里选定）。
   - 用户觉得好看的：克莱因蓝 + 朱橙小面积撞色；大面积单一底色上，蓝色只出现在贴纸里（像宝石一样点缀）。
   - 用户觉得不协调的：整屏克莱因蓝做底；炭黑底上放大块蓝色物件；一屏四五种颜色抢戏。
   - 酒红 + 金（主页背景板的配色）没有采用；主页背景板建议按新配色重做。
4. **简约高级**：删掉角标预留位、时间码、HUD 这类装饰。
5. **知识卡片 + 透明底图片素材必须保留**：它们是丰富画面的主要手段。
6. **拆库**：知识卡片拆成「排版库（构图 + 图片位，复用挖洞号 49 张的构图，图片风格不匹配就留占位）」和「信息卡片库（信息输出的关键，搭配生图和用户素材）」，另做全新的动效库。

7a. **主页背景板**：选方案 A，用户已按新配色自行修改主页背景板；视频不引入酒红 + 金（两者混用会出现「差一点的同色」和两个强调色抢戏）。
7b. **库结构**（2026-11-26）：新仓库必须有信息卡库、排版库、动效库；除生成的贴纸外，还要有一个类似挖洞号「SC-01 + 雕塑」的图片素材库（白帽志用自己的风格）。**2026-11-26 更新**：没有品牌层，图片素材每期都不一样，图片素材库只放风格提示词（`cards/images/styles.json`）。
7c. **空间利用率最大化**（2026-11-26）：不留人物小窗、时间码、角标位；16:9 画面尽量用满。
7d. **核心目标**（2026-11-26）：白帽志同样是知识讲解，核心是把抽象知识通过图片（贴纸、用户提供的图片素材）+ 动效 + 用户提供的录屏的综合动画讲清楚，并带来惊艳的视觉体验。

7e. **不设品牌素材层**（2026-11-26）：图片素材由用户生成提供，或按本期现生成，不需要跨期复用；品牌层暂不进 `main`。
7g. **知识卡片板块放同一个文件夹**（2026-11-26）：挖洞号的知识卡片核心 = 图片 + 画面排版 + 信息卡，拆分后仍属一个板块，放在 `main` 的 `cards/` 下（`images/`、`layouts/`、`infocards/`、`recipes/`）。动效库、排版、信息卡、图片风格用户会持续扩充。
7h. **SC02**（2026-11-26）：白帽志适配的漫画风格叫 SC02（蓝调漫画，两种做法）；之后还会扩充新风格。
7i. **信息卡圆角**（2026-11-27）：信息卡加苹果式圆角；同时用到窗口、色块、字幕底板，全片统一（视觉系统 1.3）。
7f. **`main` 只留最新两期的视频工程**（2026-11-26）；更早的归档到标签。待改造的参考代码、未确认的候选放在单独分支，不进 `main`。

## 二、流程与交付（沿用，2026-11-26 用户确认）
7. 先汇报剪辑思路 + 生图清单，确认后再出分镜和 AE 包，确认后再渲染。
8. 先交分镜（含手机竖屏模拟图）+ AE 包，不要直接渲染成片，除非用户说「直接做」。
9. 局部改动的交付方式（用户在剪映里自己剪）：
   - 可以只单独渲染某一段：前后不带转场，可直接替换进剪辑工程。
   - 可以做单镜头 AE 包：时间归零，口播 / 字幕 / 音效截同一段。
   - 字幕单独给 SRT：整片一份 + 分段一份（UTF-8，引导语不进字幕）。
   - 仓库里已有口播就自己截，不用用户再提供音频。
10. 口播会换：用户可能因节奏拖沓重新录。重新转写、重排时间轴，删掉新口播里没有的段落；旧音频和旧转写改名保留。
11. AE 包交付前检查全部通过，并如实说明没在真 AE 里测过；分镜和 AE 包一起交；AE 包必须分层。

## 三、画面文字与可读性（沿用）
12. 横屏，但手机竖着看也要清楚；字幕 50px；交付关键帧附手机竖屏模拟图。
13. 画面文字是为了让观众更好地理解和吸收干货，按「语义 + 理解门槛」取舍：
    - 口播已经说清楚、听一遍就懂的话，画面上不再重复。
    - 口播说不清楚、内容抽象时，必须上屏演示和标明：把概念拆开、把过程画出来、把关键处标出来。宁可多标一处，不要让观众听不懂。
    - 实操演示部分靠录屏 + 推镜 + 标注框，一个镜头最多一处强调。
14. 金句要有金句的分量：整期核心那句用单独的金句卡（炭黑场 + 得意黑大字 + 朱橙块），不要压在人物画面上。
15. 引导信息（点收藏、关注我、资料自取）不上屏、不进字幕；需要时做成透明底矢量动画素材单独交付：ProRes 4444 透明 MOV（首选）+ 透明 WebM + 绿幕 MP4 + PNG 序列 + 使用说明。

## 四、版式与镜头（沿用并按白帽志调整）
16. 核心实操录屏占屏约 85%，讲细节时窗口撑到约 90%。
17. 录屏一律平放，不做 2.5D 透视。
18. 卡片尽量多用，但不硬套；需要不出人物的讲解时，用全屏 B-roll 知识卡。
19. 画面不能单调：讲原理的镜头用贴纸道具把概念演出来（实物化），不要只有一个物件加两侧大字。
