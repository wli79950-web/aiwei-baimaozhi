# 决策记录 · 视觉系统 1.0 定稿（2026-11-25 ~ 26）

记录建号对话里配色和结构是怎么一步步定下来的，以后有人想改方向时先看这里，避免重走弯路。

## 配色的演变
| 轮次 | 方案 | 结果 | 原因 |
|---|---|---|---|
| 1 | 用户给两套：①金黄 / 朱砂红 / 深砖红 / 奶油白；②炭黑 / 信号朱红 / 暖米白 / 克莱因蓝 | 选②做骨架 | ①偏春节 / 国潮 / 理财，黄色在奶油白上对比只有 1.3–1.7；②的炭黑 + 朱红 + 米白几乎等于挖洞号，只有克莱因蓝是新的 |
| 2 | A 蓝版：克莱因蓝整屏做主色 | 不用 | 和头像（暖黄底）、主页背景板（酒红 + 金）对不上 |
| 3 | B 红金版：酒红主场 + 金色重点（从头像和背景板取色） | 过渡 | 和主页一致，但用户要求加回克莱因蓝 |
| 4 | 红金 + 克莱因蓝：蓝做整屏「高潮底」 | 改 | 整屏蓝不协调（帽带蓝在蓝底上对比 1.16）；炭黑底 + 蓝色公文包发闷（1.73）。用户认可「酒红底 + 蓝色只在贴纸里」 |
| 5 | 炭黑主场 + 蓝色块 | 改 | 用户提出炭黑主场更好看；蓝色在炭黑上只能做色块 |
| 6 | **炭黑 + 橙为核心，蓝为辅** | ✅ 定稿 | 用户在 4 档橙里选 B 朱橙 `#FF5A1F` |

### 为什么是朱橙 `#FF5A1F`
- 色相 16°，和挖洞号警报红 `#F2333F`（356°）差 20°；信号朱红 `#FF3B1F` 只差 11°，放在黑底上几乎是同一个红，会撞挖洞号。
- 黑底上的朱橙字对比 5.94，炭黑字放在朱橙块上 5.94，两种用法都能用于任何字号。
- 和克莱因蓝是互补色，小面积并排张力强。
- 和挖洞号靠「炭黑而非墨黑 + 克莱因蓝 + 奶油白陶瓷贴纸 + 无纸纹 / HUD」进一步拉开。

## 结构决策
- **简约版式**：用户要求删掉角标预留位、时间码等 → 不留左上角、不做 HUD / 时间码 / 编号 / 进度条。
- **知识卡片和透明底贴纸保留**：用户明确这是丰富画面的设定，不能丢。
- **拆库**：用户提出把「排版 + 图片位」做成排版库（复用挖洞号 49 张的构图），信息卡片单独成库；再加全新动效库。
- **动效全新编写**：挖洞号的动效来自 lieflat code video（PolyForm 非商业许可），白帽志若商业化会有授权风险，所以不沿用任何 lieflat 代码。
- **贴纸风格**：哑光陶瓷 3D 物件，只用奶油白 / 克莱因蓝 / 朱橙（样张阶段是金色点缀，定稿后改朱橙）；品牌符号是白帽。
- **规则沿用**：挖洞号已验证的制作流程、交付方式、AE 分层要求、移动端可读、无背景音乐、引导信息不上屏，全部沿用（2026-11-26 用户确认）。

## 主页素材
- 头像（暖黄底、奶油白毛衣）和新配色是同一暖色系，可以不动。
- 主页背景板原为酒红 + 金。讨论过「酒红 + 金作为第二种背景板和现有体系共存」：不采用。原因：酒红（359°）和朱橙（16°）是「差一点的同色」，看起来像配色失误；金和朱橙两个暖色强调色抢戏（明度差 1.96）；蓝色贴纸在酒红上 1.13；酒红色相和挖洞号警报红几乎一样。折中方案「炭黑底 + 暗红光晕」也提过。
- **用户选方案 A**：主页背景板由用户按新配色自行修改，视频保持现在这套不动（2026-11-26）。
