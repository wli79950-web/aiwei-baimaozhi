# 录屏组件（P4 建设，和信息卡库一起做）

白帽志的核心讲法之一：**用户提供的录屏是证据**，配合标注、信息卡和贴纸 / 角色，把「发生了什么」讲清楚。演示帧 F6（录屏 + 标注 + 白帽角色）在提交 `adbbc35` 里（`main` 历史中；浅克隆先 `git fetch --depth=10 origin main`）：`git show adbbc35:docs/previews/demo_F6.jpg > demo_F6.jpg`。

## 组件
| 组件 | 作用 |
|---|---|
| 窗口框 | 炭灰窗口 + 朱橙 / 奶油白三个圆点 + 等宽标题栏；平放，不做 2.5D 透视 |
| 推镜 | 缩放 + 平移关键帧，讲细节时推到局部，最大可到满屏 |
| 标注 | 朱橙框选、朱橙下划线、朱橙引线 + 结论标签（朱橙块 + 炭黑字）；一个镜头最多一处强调 |
| 光标 | 光标放大、点击涟漪 |
| 打码 | 模糊 / 色块打码（手机号、token、真实域名） |
| 联动 | 从录屏里的一行「拉出」一张信息卡；贴纸 / 白帽角色指向标注处 |

## 规则
- 核心实操录屏占画面宽 85–94%；和角色 / 信息卡同框时可以缩到约 70%，但全部内容仍要占画面 70% 以上。
- 录屏保留原色，不调色；只在上面加朱橙标注。
- AE 里录屏必须可替换：窗口边框图片层 + 录屏预合成（原片 + 时间重映射 + 推镜关键帧 + 标注形状层），见 `docs/rules/AE包规范.md`。
