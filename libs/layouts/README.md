# 排版库（P3 建设）

只管**构图和槽位**，不含颜色、字体、动效。由「艾唯说挖洞」49 张知识卡片的构图迁来（只借构图，不带任何样式和样例素材），图片风格不匹配的位置一律留占位框。

## 每个排版 = 一个 `layout.json` + 一张线框预览
```json
{
  "id": "L-K08",
  "from": "K8 编号网格",
  "function": "讲步骤 / 流程（3–6 步）",
  "scene": ["A", "B"],
  "aroll": false,
  "slots": [
    { "id": "t1", "type": "title", "rect": [96, 96, 1200, 110] },
    { "id": "c1", "type": "card",  "size": "L", "rect": [96, 300, 560, 240], "need": "步骤卡：编号 + 名称 + 贴纸" },
    { "id": "m1", "type": "media", "rect": [450, 320, 180, 180], "need": "贴纸：本步骤的物件" }
  ]
}
```
- 槽位类型：`title` 标题、`card` 信息卡、`media` 贴纸 / 截图 / 用户素材、`person` A-roll 人物、`label` 标注；另外固定一块 `subtitle-safe` 字幕安全区（底部居中，距底 104px）。
- 尺寸档：S 336×192 · M 528×288 · L 720×384 · XL 1104×576（`tokens/brand.json` → `layout.size_class`）。
- 网格：左右页边距 96px，最小单位 48px；白帽志不留左上角角标位，迁移时可以把原来避让 IP 区的元素往左上放。
- 检查工具 `tools/layout_lint.py`（P3）：槽位越界、压到字幕区、字号低于 52px、违反配色规则。
