# 镜头配方表（P6 建设）

「什么内容 → 用哪个排版 + 哪些信息卡 + 哪套动效 + 哪个场景」。先把挖洞号 49 种叙事功能改写成配方（例：「一个名词是什么」「二选一对比」「修复前后」「证据只看一行」），再补白帽志新增的 6 种：

| 新增叙事功能 | 用在哪 |
|---|---|
| AI 对话 / 提示词 | 演示怎么问 AI、AI 怎么答 |
| AI 输出 vs 人工复核 | 讲 AI 的结论哪些要人确认 |
| 技能树 / 学习路线 | 就业、入门路线 |
| 岗位 JD 拆解 | 网安就业 |
| 工具对比 | AI 工具 / 安全工具横评 |
| 面试题 | 就业 |

格式：`recipes.json`（机器读）+ `recipes.md`（人看），每条配方附一张示例关键帧。
