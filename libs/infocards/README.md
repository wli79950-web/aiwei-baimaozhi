# 信息卡片库（P4 建设）

信息输出的关键组件，放进排版库的 `card` 槽位，常搭配贴纸和用户提供的素材。每个组件都要写清楚：接收哪些内容、可选的尺寸档（S / M / L / XL）、A 炭黑场 / B 奶油白场两种配色、动效拍点（入场 / 强调 / 退场）。

## 首批计划（约 20 个）
标题组 · 关键词卡 · 定义卡 · 数字卡 · 步骤卡 · 对比芯片 · 引用卡 · 清单卡 · 标签 / 胶囊 · 代码片段卡 · 终端卡 · 截图框 · 手机屏幕 · AI 对话卡 · 「AI 输出 vs 人工复核」卡 · 岗位 / JD 卡 · 技能树节点 · 风险卡 · 结论卡 · 档位卡

录屏相关的组件（窗口、推镜、标注、光标、打码、联动）单独放在 `libs/screencast/`。

## 现在可用的
`engine/base.css` 里的场景默认样式：`.card`（炭灰 / 卡片白）、`.card.lit`（亮卡）、`.card.hot`（朱橙当前项）、`.blk`（朱橙块 + 炭黑字）、`.aux`（蓝块 + 奶油白字）。演示见 `docs/previews/src/demo.html`。
