# 知识卡片板块

挖洞号的一张知识卡片 = **图片 + 画面排版 + 信息卡**（再加动效）。白帽志把这三样拆开，各自成库、各自扩充，但仍属于「知识卡片」这一个板块，所以放在同一个文件夹下：

| 目录 | 管什么 | 来源 / 扩充 |
|---|---|---|
| `layouts/` | **排版**：构图 + 槽位（标题位、信息卡位、图片位、字幕安全区），不含颜色和动效 | 挖洞号 49 张卡的构图迁来（P3 ✅，50 个），之后持续扩充 |
| `infocards/` | **信息卡**：承载信息的组件（关键词、定义、数字、步骤、对比、清单、代码、AI 对话……） | P4 首批约 20 个，之后持续扩充 |
| `images/` | **图片**：风格提示词（`styles.json`：real 写实为核心、anime 动漫为辅，另有 SC02、tone……）、后期处理、风格样张 | 风格持续扩充；图片每期现生成 |
| `recipes/` | **配方**：一张完整的知识卡片 = 哪个排版 + 哪些信息卡 + 哪种图片 + 哪套动效 | P6；把挖洞号 49 种叙事功能改写成配方 |

动效不在这个文件夹里：动效库在 `engine/motion/`，知识卡片、录屏、转场都用它。背景板（`libs/backgrounds/`）和录屏组件（`libs/screencast/`）也不属于卡片。

## 一张卡片怎么搭
1. 按口播的叙事功能查 `recipes/`，找到对应的排版。
2. 选场景（A 炭黑 / B 奶油白）和背景板。
3. 往排版的槽位里填信息卡（`infocards/`）和图片（按 `images/styles.json` 现生成，或用用户素材）。
4. 套动效（`engine/motion/`）。

## 和挖洞号的对应
挖洞号 `cards/` 里一张卡把几样写死在一起（例：K1 票据卡 = 票据版式 + 档位信息卡 + 3D 物件贴纸 + 弹入动效）。白帽志拆开后：K1 的**构图**进 `layouts/`，**档位卡**进 `infocards/`，**物件图**按 `images/` 的 `real` 写实风格每期现生成（1.4 起；原 `sticker` 陶瓷贴纸停用），**动效**来自 `engine/motion/`，四者的组合写进 `recipes/`。只借构图，不搬挖洞号的样式和素材。
