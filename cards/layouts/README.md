# 排版库（P3 建设中）

只管**构图和槽位**，不含具体颜色值、字体和动效。由「艾唯说挖洞」49 张知识卡片的构图迁来（只借构图，不带任何样式和样例素材），图片风格不匹配的位置一律留占位框。之后持续扩充（白帽志新增的排版用 `L-W01` 起编号）。

## 文件
| 文件 | 说明 |
|---|---|
| `L-xxx.json` | 一个排版一个文件，文件名 = id |
| `previews/L-xxx.jpg` | 线框预览（`node tools/layout_preview.js` 生成，960×540） |
| `../../docs/previews/layouts/sheet.jpg` | 全部排版的总览板 |

## `layout.json` 写法
```json
{
  "id": "L-K08",
  "name": "编号网格",
  "from": "K8 编号网格",
  "function": "讲步骤 / 流程（3–6 步）",
  "scene": ["A", "B"],
  "slots": [
    { "id": "t1", "type": "title", "rect": [64, 56, 1200, 128], "font_px": 112, "need": "小节标题" },
    { "id": "c1", "type": "card", "size": "custom", "rect": [64, 208, 576, 672], "font_px": 56, "subject": true, "count": [3, 6], "need": "步骤卡：编号 + 名称" },
    { "id": "m1", "type": "media", "rect": [400, 192, 240, 240], "over": ["c1"], "need": "贴纸：本步骤的物件" }
  ]
}
```

### 排版字段
| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✓ | `L-K08`（迁自挖洞号 K8）、`L-N04`（迁自 N4）、`L-W01`（白帽志新增） |
| `name` | ✓ | 排版名 |
| `from` | ✓ | 迁自哪张卡；白帽志新增写「白帽志新增」 |
| `function` | ✓ | 叙事功能：这个构图用来讲什么 |
| `scene` | ✓ | 适用场景 `A` 炭黑 / `B` 奶油白 |
| `canvas` | | 默认 `[1920, 1080]`；竖屏写 `[1080, 1920]` |
| `notes` | | 备注 |

### 槽位字段
| 字段 | 说明 |
|---|---|
| `id` `type` `rect` `need` | 必填。`rect` = `[x, y, 宽, 高]`（px，最好是 8 的倍数）；`need` 写这个位置放什么 |
| `type` | `title` 标题 · `card` 信息卡 · `media` 贴纸 / 截图 / 用户素材 · `screen` 录屏窗口 · `person` 人物 · `label` 标注 |
| `subject` | `true` = 主体（贴纸、录屏或一组信息卡）；每个排版至少一个 |
| `font_px` | `title` / `card` / `label` 必填：这个位置的最小字号 |
| `size` | `card` 必填：`S` 336×192 · `M` 528×288 · `L` 720×384 · `XL` 1104×576，或 `custom`（宽高为 48 的倍数） |
| `bleed` | `true` = 可以出血（只限 `media` / `screen` / `person`，至少一半在画面内） |
| `over` | 有意叠放在哪些槽位上面，如贴纸压在卡片角上 `["c1"]` |
| `count` | 重复槽位的数量范围，如步骤卡 `[3, 6]` |
| `person_optional` | `media` 槽位：原来是 A-roll 人物位，以后有真人口播可切回 `person` |
| `decor` | `label`：英文小标注（装饰），每屏最多一处，字号可以低于 52 |
| `fill` / `ink` / `stroke` | 配色角色（不是色值）：`fill` = `none` / `card` / `card_lit` / `accent` / `aux`；`ink` = `title` / `body` / `accent` 或色板 key；`stroke` = 描线色板 key。只在构图本身依赖色块时写 |

## 检查：`python3 tools/layout_lint.py`
数值全部从 `tokens/brand.json` 读。错误（✗）必须改，提醒（!）看情况。
- **边界**：不出血的槽位在页边距内（左右 64 / 上下 56px）；出血槽位至少一半在画面内；带字的槽位不能出血。
- **字幕安全区**：底部居中，距底 104px，高 84px（字号 50 + 上下内边距），宽 1560px。标题、信息卡、标注不许压；贴纸、录屏、人物可以在字幕底板下面。
- **字号**：标题 ≥ 104，有意义的文字 ≥ 52；英文小标注每屏最多一处。
- **一屏一个标题**；两个不带底的文字槽位不能重叠；其他重叠要用 `over` 声明。
- **尺寸档**：信息卡写 `size`，和 `rect` 对得上。
- **录屏窗口**：宽 85–94%（和角色 / 信息卡同框可缩到约 70%，低于 68% 报错）。
- **不做人物小窗**：`person` 槽位小于画面 25% 报错。
- **配色**：`fill` / `ink` / `stroke` 按场景解析后，不得出现三条禁用组合，文字对比 ≥ 4.5；朱橙块 + 蓝块合计 ≤ 画面 15%。
- **利用率**：主体槽位的并集 ≥ 画面 45%；全部槽位铺开的范围（外接矩形）≥ 画面 70%。

自检：`python3 tools/test_layouts.py`（拿 `tools/fixtures/layouts/L-T01.json` 逐条改坏，确认每条规则都拦得住，并检查本目录全部排版通过）。

## 线框预览：`node tools/layout_preview.js`
A 炭黑场配色画线框：虚线框 = 页边距，斜线条 = 字幕安全区，朱橙括角 = 主体，朱橙点线 = 出血，交叉框 = 图片位。文字按 `font_px` 的真实大小画，用来判断手机竖拿时看不看得清。

## A-roll 版式怎么迁
约 12 张原本带人物的版式（K5、K10、K11、K12、K21、K23、K25、K26、K27、N4、N11–N14）：人物位默认改成 `media` 槽位（放角色、贴纸、双色调照片或用户素材），并标 `"person_optional": true`。以后若有真人口播，再把这个槽位切回 `person`。人物圆形小窗一律不迁。

## 迁移原则
白帽志不留左上角角标位、不做人物小窗：把原来避让 IP 区、人物小窗的空间全部用起来，主体尽量放大。原构图里的标题位置、主体与信息卡的相对关系保留；尺寸按 1920×1080、64 / 56px 页边距重新排。
