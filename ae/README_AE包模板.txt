{TITLE} · AE 重建包
========================================

一、怎么用
1. 先装字体：打开 fonts 文件夹，选中全部 .ttf → 右键 →「为所有用户安装」，然后重启 AE。
   本期用到的字体（PostScript 名）：{FONTS}
2. AE 里新建（或打开）一个工程 →「文件 → 脚本 → 运行脚本文件」→ 选 {JSX}。
   脚本会在项目面板里建三个文件夹：素材、镜头、部件预合成；主合成「{MAIN}」（{DUR} 秒，{SHOTS} 个镜头，1920×1080，60fps）。
3. 素材在 assets 文件夹，脚本按相对路径找：整个包解压后不要拆开挪动。

二、图层结构（每个镜头一个合成，从下往上）
- 背景板_BG3 / 背景板_BG2：库里的底板图片（单独一层）。
- 背景动态_点阵 / 十字标 / 焦点光晕 / 焦点刻度环 / 焦点刻度：动态背景，每个单独一层，能隐藏、能替换；
  焦点刻度每秒转 4°。SVG 原件在 assets/svg（AE 里用的是同尺寸的 PNG）。
- 画面元素：每张卡片 / 贴纸 / 文字是单独的图层；有多个部件的卡片在「部件预合成」里，倾斜在预合成图层上转。
  · PNG 层 = 底卡、描边、图标、贴纸（文字已经抠掉）；文字全部是 AE 文字层，能直接改字。
  · 部件里的文字层挂在 PNG 层下面（父子关系），透明度用表达式跟着 PNG 层走：移动 PNG 层，字跟着走。
  · 入场关键帧和网页同一份时间表、同一条缓动曲线（白帽志动效库 BMAE）。
- 录屏窗口：「录屏窗口_边框」图片层 +「录屏窗口_画面（预合成）」。
  · 预合成里的「录屏原片」就是录屏素材：项目面板里右键 →「替换素材」即可换录屏（分辨率保持一致，推镜和打码位置才对得上）。
  · 原片层带时间重映射（换页 / 定格）和缩放、位置关键帧（推镜）；打码（实色块）和标注框挂在原片层下面，跟着推镜动。
- 画面顶部 76px 是章节进度条区（你剪辑时放），这里只有背景，没有任何内容图层。

三、需要留意
{WARN}
- 还原对比 文件夹：每个镜头「原画面（网页）/ 用导出的图层拼回去 / 差异」三联图，用来确认图层位置和网页一致。
- 本包只在「模拟 AE 对象模型」里跑通过（按你的 AE 24.6.2 探测报告，见 模拟测试报告.txt），没有在真 AE 里运行过。
  如果运行时弹出「重建中断」，请把弹窗截图发给我。
- AE 24.3 以下没有逐字设字体的接口：中英混排的文字会整段用第一个字体（脚本会在结束时提示）。
